# XauSync AI Web

> **Project Status: Discontinued / Portfolio Archive**

The marketing and legal-information website of XauSync AI.

## Project Background

I created XauSync AI as a research project to understand financial markets and the tooling around them. I used it to explore market data and news, trading-platform APIs, technical indicators, AI-assisted analysis, and the integration and automation work needed to connect them. The goal was practical experience with these technologies and an understanding of how they can be used in software products.

## Key Features

- Landing page, About, and Disclaimer pages
- Privacy Policy and Terms of Use pages
- Mobile-specific routes, including account deletion instructions
- Localization support

## Tech Stack

- Next.js (Pages Router), React, TypeScript
- Material UI with Emotion
- Lingui, Zod, Axios

## Project Timeline

- Started: February 2026
- Discontinued: May 2026
- Status: Discontinued — Portfolio Archive

## Project Status

The project is discontinued and no longer maintained. I closed it because it lost its relevance for me, not because it could not be finished technically. The main learning goal of the project was achieved. The related production services are not maintained, some external integrations may no longer work, and the code is not intended to run in production without new credentials and infrastructure. Credentials and environment files are not included.
